- No local screenshot files with verifiable Meridian/interface context were found in the initial repository/Downloads asset-name search. Unlabelled `diagram*.png` files were not assumed to be Meridian evidence and were not repurposed.

- Seven screenshots were generated from the actual local Meridian UI, served with a new SQLite file inside `project_report_output`. They are labelled as local implementation screenshots, not screenshots of the deployed build. No production network data was changed.
- Screenshot locations are `assets/screenshots/`; figures in the report identify the capture context and do not claim access to unavailable discussion attachments.
